Trabajo destacado

Sistema de Reservas de Canchas

Plataforma full-stack para la gestión de reservas de canchas deportivas: los usuarios consultan disponibilidad y reservan horarios, mientras los administradores gestionan canchas y reservas desde un panel dedicado. Backend en NestJS con TypeORM sobre PostgreSQL; frontend en Next.js con TypeScript y Tailwind v4.

Stack técnico

NestJS TypeORM PostgreSQL Next.js TypeScript Tailwind v4

Decisiones técnicas

  • Lock de concurrencia: bloqueo con pg_advisory_xact_lock a nivel de transacción para evitar reservas dobles sobre el mismo horario y cancha.
  • Rate limiting en login: throttling por IP/usuario para mitigar ataques de fuerza bruta sobre las credenciales.
  • Disponibilidad en tiempo real: el filtro de horarios cruza las reservas existentes contra el rango solicitado antes de confirmar, evitando condiciones de carrera visibles para el usuario.

Traductor de Documentos con IA

Herramienta para traducir documentos completos (EPUB, PDF, TXT) del inglés al español preservando el formato original, usando LLMs con contexto y glosario para lograr traducciones naturales en vez de literales. Backend en FastAPI con una representación intermedia (Document → Chapter → Block) que desacopla el formato de entrada del proceso de traducción; frontend en React con seguimiento de progreso en tiempo real. Actualmente en mejora activa: migrando del modelo local (Ollama) a uno más grande para aumentar la calidad de traducción y reducir la pérdida de contexto en documentos largos.

Stack técnico

Python FastAPI SQLite React Tailwind CSS PyMuPDF ebooklib Anthropic SDK

Decisiones técnicas

  • Representación intermedia: arquitectura Document→Chapter→Block que desacopla extracción, traducción y reconstrucción — agregar un formato nuevo no toca el núcleo de traducción.
  • Cliente LLM intercambiable: capa de abstracción que alterna entre un modelo local (Ollama) y la API de Claude sin cambiar el resto del sistema, con reporte de uso de tokens desde el diseño.
  • Reflow de PDF: reconstrucción con la API Story de PyMuPDF para manejar que el texto traducido no ocupa el mismo espacio que el original, en vez de forzar posiciones fijas.
