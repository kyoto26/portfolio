Trabajo destacado

Sistema de Reservas de Canchas

Plataforma full-stack para la gestión de reservas de canchas deportivas: los usuarios consultan disponibilidad y reservan horarios, mientras los administradores gestionan canchas y reservas desde un panel dedicado. Backend en NestJS con TypeORM sobre PostgreSQL; frontend en Next.js con TypeScript y Tailwind v4.

Stack técnico

NestJS TypeORM PostgreSQL Next.js TypeScript Tailwind v4

Decisiones técnicas

  • Lock de concurrencia: bloqueo con pg_advisory_xact_lock a nivel de transacción para evitar reservas dobles sobre el mismo horario y cancha.
  • Rate limiting en login: throttling por IP/usuario para mitigar ataques de fuerza bruta sobre las credenciales.
  • Disponibilidad en tiempo real: el filtro de horarios cruza las reservas existentes contra el rango solicitado antes de confirmar, evitando condiciones de carrera visibles para el usuario.
